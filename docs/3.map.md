# Map — `useMap`

`useMap` manages the MapLibre GL JS map lifecycle: creation, globe projection, view persistence, and cleanup.

---

## URL hash — map view sharing

The app reads and writes the map view to the URL hash in [OpenStreetMap format](https://wiki.openstreetmap.org/wiki/Browsing#Linking_to_a_specific_location), extended with camera tilt and bearing:

```
#map={zoom}/{lat}/{lng}/{pitch}/{bearing}
```

Example: `#map=16/50.653900/-128.009400/45/120`

Zoom is a whole number, latitude/longitude carry six decimal places, and pitch/bearing are whole degrees (bearing normalised 0–360). On read, a three-segment `#map={zoom}/{lat}/{lng}` hash is also accepted, with pitch and bearing defaulting to 0.

If the URL contains a `#map=…` hash on page load, it is used as the initial map view — taking priority over any previously persisted view. This lets you share a specific location by URL.

As the map is panned or zoomed, the URL hash is updated automatically (throttled to once per second). The hash and `localStorage` view are always kept in sync.

[`formatUrlHash()`](../src/composables/useUrlHash.js) is the single source of truth for the format: `useMap` uses it for the live hash, and the Info panel uses it for its share URL (see [UI](./4.ui.md)).

---

## Globe projection

Globe projection is always active. On every load, `useMap` calls `map.setProjection({ type: 'globe' })` on the `style.load` event. MapLibre automatically transitions between globe (low zoom) and mercator (high zoom) — zooming out from any location will return the user to the 3D globe view.

On a true cold start (no stored view, no URL hash), the map fits the country resolved by the cold-start cascade — see [Cold-start country focus](#cold-start-country-focus). Returning users are taken to their last-known location; zooming out from anywhere returns to the globe.

## `useMap` API

### Initialising the map

Called once from `App.vue` with a Vue template ref for the map container:

```js
import { ref } from "vue";
import { useMap } from "@/composables/useMap.js";

const mapContainer = ref(null);
useMap(mapContainer, {});
```

```html
<div ref="mapContainer" class="ogis-map" />
```

`useMap` registers `onMounted`/`onUnmounted` hooks. On mount, a `maplibregl.Map` is created with the defaults from [`src/defaults/maplibre.js`](../src/defaults/maplibre.js) — the OpenGIS outdoors style, initial `[0, 0]` centre at zoom 1, and MapLibre's built-in attribution control disabled (`attributionControl: false`) in favour of the custom chip described in [UI](./4.ui.md). On unmount, the map is destroyed and an `emitter.emit('destroy')` is fired for feature cleanup.

### Accessing the map instance

From any composable or feature after setup:

```js
import { getMapInstance } from "@/composables/useMap.js";

const map = getMapInstance(instanceId);
if (map) map.addSource("my-source", { type: "geojson", data: { ... } });
```

`getMapInstance` returns the live map or `null` before load. Use it in geolocation callbacks and event handlers where a Vue inject context is unavailable.

### View persistence

The map center, zoom, pitch and bearing are saved to `localStorage` under `ogis_view_{instanceId}` after every movement (throttled to 1 s). On reload the saved view is restored via `map.jumpTo()`; older stored views without pitch/bearing are read as 0.

Initial-view priority is: `?country=` override → URL hash → stored view → cold-start country focus. On a true cold start — or when `?country=` forces the focus — `mapView` stays `null` until the country fit completes; the fit's `moveend` persists the view, so the share URL appears once the map has been framed.

### Cold-start country focus

On load, the `style.load` handler resolves the initial focus from these sources, highest priority first:

1. **`?country=` query param** — forces the focus and outranks both the `#map=` hash and any stored view. `?country=XX` (a valid alpha-2 code, case-insensitive) fits that country; `?country=random` fits a random country on every load — the param survives `replaceState`, so a refresh makes a fresh draw. Empty or unknown values are ignored, so the normal rules apply.
2. **`#map=` URL hash** — an explicitly shared view (see [URL hash](#url-hash--map-view-sharing)).
3. **Stored view** — the last view persisted to `localStorage`.
4. **Cold-start cascade** — on a true cold start (neither of the above):
   1. `countryCodeFromTimeZone()` ([`src/utils/countries.js`](../src/utils/countries.js)) resolves the browser's IANA timezone to a region using a lazily built, cached reverse map of `Intl.Locale("und-<code>").getTimeZones()`. It is feature-checked (`getTimeZones` absent → `null`), and `UTC`/unknown zones resolve to `null`.
   2. The first raw browser language (`navigator.languages[0]` — not the resolved app locale or `?locale=`) is passed to `countryCodeFromLocale()`, which maximizes it with `Intl.Locale(...).maximize().region` — `en-GB` → `GB`, `fr` → `FR` — and returns `null` when no region is available.
   3. If neither resolves, a random country is chosen.

`countryCodeToBounds(code)` resolves the region against the frozen `COUNTRY_BOUNDS` table (bounding boxes migrated unmodified from Waymark-JS's `country_code_to_bounds`), preferring the `WRAP_OVERRIDES` table where present; an unknown or missing code falls back to a random country. `WRAP_OVERRIDES` holds the antimeridian-crossing countries (FJ, RU) with west > east — bounds derived once from Natural Earth 110m admin-0. MapLibre's `fitBounds` → `cameraForBounds` calls `adjustAntiMeridian()`, which unwraps them automatically, so no special call-site handling is needed.

The fit uses `map.fitBounds(bounds, { padding, duration: 0 })`, where `padding = Math.round(min(containerWidth, containerHeight) * 0.1)` — proportional to the smaller viewport axis, so framing stays consistent across phone and desktop. `duration: 0` completes synchronously. When the side panel is open on desktop, the map container itself is narrowed (`left`/`width` via `.ogis-map.panel-open`, [`src/assets/sass/theme.scss:249`](../src/assets/sass/theme.scss#L249)), so the fit centres the country in the visible map area.

Because the fit is a programmatic move, the `moveend` handler persists it to `localStorage` and the URL hash and emits `view:change` — the same path as any other camera move. No hash is written from the constructor defaults before the fit. Returning users and shared `#map=` links are unaffected unless a `?country=` override is present.

### Scale bar

A `ScaleControl` is added to the bottom-left corner. The unit (metric/imperial) follows the OS/browser region (inferred from the preferred language) and updates reactively.

### Multilingual map labels

On load, `useMap` applies a coalesce expression to every OSM name field across all symbol layers:

```
name:{locale}  →  name  →  name:en
```

The expression updates reactively when the OS/browser language changes — no page reload required.

See [Locale](./6.locale.md#osm-multilingual-names) for details.

### Returned API

```js
const { map, mapView } = useMap();
```

| Property  | Type                                            | Description                                     |
| --------- | ----------------------------------------------- | ----------------------------------------------- |
| `map`     | `maplibregl.Map \| null`                        | Active MapLibre instance, or `null` before load |
| `mapView` | `Ref<{lat, lng, zoom, pitch, bearing} \| null>` | Reactive current view                           |
