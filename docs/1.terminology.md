# Terminology

> Shared project language for ogis.app. Definitions here must be accurate and
> verifiable against the code — they are used across docs, tests and commits.

## Demo area

The single, configurable geographic area for which the E2E suite vendors map
assets. Its centre is the project's default demo coordinates — the Scarlet Ibis
Pub, Holberg, British Columbia, Canada (`50.6539, -128.0094`). The area is
defined once in
[`tests/e2e/fixtures/map/demoArea.mjs`](../tests/e2e/fixtures/map/demoArea.mjs),
the single source of truth for:

| Config             | Value                                                                            | Meaning                                         |
| ------------------ | -------------------------------------------------------------------------------- | ----------------------------------------------- |
| `center`           | `{ lat: 50.6539, lng: -128.0094 }`                                               | Canonical demo centre                           |
| `bounds`           | `west -128.05`, `south 50.62`, `east -127.97`, `north 50.68`                     | Box the fixture set covers                      |
| `screenshotZoom`   | `16`                                                                             | Zoom for the committed screenshot matrix        |
| `coverageZooms`    | every integer `0`–`16`                                                           | Zooms the fixture set covers                    |
| `excludedSources`  | `attribution`, `esri-satellite`                                                  | Sources deliberately not vendored, with reasons |
| `committableHosts` | `tiles.openfreemap.org`, `tiles.mapterhorn.com`, `tile.ogis.app`, `www.ogis.org` | Hosts whose assets may be committed             |
| `glyphRanges`      | `0-255`                                                                          | Committed glyph range per font stack            |
| `spriteScale`      | `1`                                                                              | Only the 1× sprite atlas is vendored            |

Consumers: the fixture generator (`refresh.mjs`), the tile enumeration
(`enumerate.mjs`), the UI-states screenshot spec (`ui-states.spec.js`) and the
demo-area unit test. The README hero spec (`readme.spec.js`) deliberately does
not use the fixture set — its heroes are live random-country captures.

Changing the demo area means editing that file, regenerating the fixtures
(`npm run fixtures:refresh`) and regenerating the committed screenshots.

## Fixture set

The committed, generated map assets that the E2E suite serves same-origin, so
every spec except the deliberately live README hero captures makes **zero live
external requests**:

- [`style.json`](../tests/e2e/fixtures/map/style.json) — the canonical fixture
  style. The generator fetches the live production style and rewrites every
  committable-host URL (sources, glyphs, sprites) into the
  `__E2E_MAP_BASE__/<host>/<path>` placeholder form; excluded hosts stay live
  in the style.
- `site/**` — the vendored assets, keyed by host and path (`site/<host>/<path>`,
  e.g. `site/tile.ogis.app/…`, `site/www.ogis.org/…`). Glyph directory names
  are URL-encoded.
- [`site.manifest.json`](../tests/e2e/fixtures/map/site.manifest.json) — every
  stored path with its byte count, source and zoom, plus the expected-but-absent
  (`204`/`404`) tiles. The manifest-completeness unit test asserts every padded
  demo-area tile is accounted for.

The set is served by the E2E-only Vite middleware
([`vitePlugin.mjs`](../tests/e2e/fixtures/map/vitePlugin.mjs)) under
`/__e2e_map__/**`, registered only when `VITE_E2E_FIXTURES=1` (set by
`playwright.config.js`'s webServer env). The context-level stub
([`mapAssets.js`](../tests/e2e/helpers/mapAssets.js)) serves the pinned style
with the placeholder substituted, serves Esri World Imagery a fast `404`, and
blocks any other external request.

**Degradation policy.** Missing tiles and glyph ranges degrade to an instant,
CORS-permissive empty `200`; a missing TileJSON descriptor gets a stub `tiles`
template that the middleware answers with empty `200`s. A missing sprite or
style fails loudly with a `404`, so drift is visible.

**Excluded sources.** `demoArea.mjs` lists the two sources deliberately not
vendored:

- `attribution` — metadata-only; declares no tiles or URL.
- `esri-satellite` — Esri World Imagery licensing excludes redistribution. Its
  URL stays live in the canonical style, but the E2E stub serves it a fast
  `404`, exercising the app's graceful-degradation path.

**Refresh workflow.** `npm run fixtures:refresh` runs
[`refresh.mjs`](../tests/e2e/fixtures/map/refresh.mjs), which fetches the live
style and, for each covered zoom, downloads the demo area padded by one tile
margin — plus glyphs and sprites — and rewrites the manifest. It is a manual
local step, deliberately **not** run in CI; run it when the upstream style
changes materially, review the diff and commit. `.prettierignore` excludes
`tests/e2e/fixtures/` (generated/vendored).

## Core terms

- **Instance** — one app context per page/iframe; `instanceId` comes from `?id=`
  (default `app`) and scopes persisted state. Keys are
  `ogis_{namespace}_{instanceId}`. See [Instances](./3.instances.md).
- **Feature** — a plain object with an `install(ctx)` method that registers a
  panel and/or corner chip from `src/main.js`. See [Features](./10.features.md).
- **`ogis.*` style properties** — GeoJSON feature properties that drive the
  `useGeoJSON` layers: `ogis.color`, `ogis.width`, `ogis.opacity`,
  `ogis.radius`, `ogis.fillOpacity`. See [GeoJSON](./6.geojson.md).
- **Map readiness signals** — `data-map-ready` (set at `style.load`) and the
  predicate-driven `data-map-idle`. See
  [Map — map readiness signals](./4.map.md#map-readiness-signals).
- **Cold-start country focus** — the timezone → raw browser language → random
  cascade that frames the map on a true cold start, overridable with
  `?country=`. See
  [Map — cold-start country focus](./4.map.md#cold-start-country-focus).
