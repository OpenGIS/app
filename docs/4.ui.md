# UI — `useUI`

`useUI` manages all application UI state: responsive breakpoints, the side panel, and first-load detection. The map chrome is two components — the corner controls overlay (`src/components/ui/controls.vue`) and the side panel (`src/components/ui/panels.vue`). There is no top navigation bar.

---

## Usage

```js
import { useUI } from "@/composables/useUI.js";

const { isDesktop, isPanelVisible, setActivePanel, openPanel } = useUI();
```

State is cached per instance in a module-level `Map` keyed by `instanceId` (see [Instances](./2.instances.md)).

---

## Responsive breakpoints

`useUI` tracks `window.innerWidth` via a resize listener and exposes three computed flags.

| Computed | Type | Condition |
|----------|------|-----------|
| `isDesktop` | `boolean` | `width >= 992px` |
| `isTablet` | `boolean` | `768px ≤ width < 992px` |
| `isMobile` | `boolean` | `width < 768px` |

The corner chips render at every breakpoint; only the panel behaviour changes with width.

---

## Corner controls

[`src/components/ui/controls.vue`](../src/components/ui/controls.vue) renders a full-screen, click-through overlay (`.onrte-controls`) with four corner clusters (`.onrte-corner--tl` / `--tr` / `--br` / `--bl`):

| Corner | Control | ID |
|--------|---------|----|
| Top-left | Menu chip — toggles the side panel | `#menu-button` |
| Top-right | Locate chip (GPS cycle) | `#locate-button` |
| Bottom-right | Feature buttons registered with `position: 'bottom-right'` (e.g. Record, `#recordings-button`) | feature-defined |
| Bottom-left | Attribution chip — opens the Info panel | `#attribution-button` |

- Every control is a **chip** — the `chip` variant of `IconButton` (`.icon-btn--chip`), a horizontal glass pill.
- Features register corner buttons with `addButton({ …, position: 'bottom-right' })`. Buttons without that position are not rendered ([`controls.vue:17`](../src/components/ui/controls.vue#L17)).
- On desktop the overlay mirrors the panel shift (`.onrte-controls.panel-open`), keeping controls over the visible map.
- The **attribution chip** shows the live style attribution, assembled by `buildAttribution` ([`src/utils/attribution.js`](../src/utils/attribution.js)) and exposed reactively by [`useAttribution`](../src/composables/useAttribution.js). It starts expanded, collapses to icon-only on the first map drag (MapLibre parity) and never expands again. Clicking it opens the Info panel. MapLibre's built-in attribution control is disabled (`attributionControl: false` in [`src/defaults/maplibre.js`](../src/defaults/maplibre.js)).

## Panel

The side panel shows one active tab at a time. Built-in tabs: `info` (default) and `settings`. Features add tabs via `addButton({ panel: { ... } })` (e.g. Recordings) or register a panel-only tab (no corner button) via `addPanel({ id, icon, title, component })` — pushed into the `navigatorPanels` registry and rendered in `.panel-nav` via `panelTabs` ([`src/components/ui/panels.vue:35`](../src/components/ui/panels.vue#L35)). With the core features installed, the tab strip is Info, Settings, Recordings, Offline Maps and Routes.

The Info panel ([`src/components/panels/info.vue`](../src/components/panels/info.vue)) merges the former View, About and Privacy panels: Map View (share URL, copy, OpenStreetMap links), About and Privacy as summaries with `<details>` disclosures, and the Attribution section.

### `setActivePanel(id)` — switch active tab

```js
setActivePanel("settings");
```

Emits a `panel:change` event.

### `openPanel()` — open the panel

```js
setActivePanel("record");
openPanel();
```

Sets both `isPanelVisible` and `isPanelExpanded` to `true`.

### `togglePanel()` / `closePanel()`

- `togglePanel()` — opens if closed, closes if open
- `closePanel()` — closes the panel without changing the active tab

## Full API

### State (refs)

| Name | Type | Description |
|------|------|-------------|
| `width` | `number` | Current `window.innerWidth` |
| `isPanelVisible` | `boolean` | Side panel open |
| `isPanelExpanded` | `boolean` | Panel expanded (mobile) |
| `activePanel` | `string` | Active panel tab ID (default: `'info'`) |
| `isFirstLoad` | `boolean` | True when no persisted view exists |
| `showAboutModal` | `boolean` | Welcome modal visible |

### Computed

| Name | Type | Description |
|------|------|-------------|
| `isDesktop` | `boolean` | `width >= 992px` |
| `isTablet` | `boolean` | `768px ≤ width < 992px` |
| `isMobile` | `boolean` | `width < 768px` |

### Actions

| Name | Signature | Description |
|------|-----------|-------------|
| `setActivePanel` | `(id)` | Switch tab, emit `panel:change` |
| `openPanel` | `()` | Open and expand panel |
| `togglePanel` | `()` | Toggle open/closed |
| `closePanel` | `()` | Close panel |
| `togglePanelExpanded` | `()` | Toggle expanded state |
| `setPanelExpanded` | `(value)` | Set expanded state |
| `setFirstLoadComplete` | `()` | Mark first load complete |
| `closeAboutModal` | `()` | Hide modal, mark first load complete |
| `openAboutModal` | `()` | Show modal |

## CSS classes

The main structural classes used by the app:

| Class | Element |
|-------|---------|
| `.onrte-root` | Root div wrapping everything |
| `.onrte-controls` | Corner-controls overlay (click-through) |
| `.onrte-corner--tl` / `--tr` / `--br` / `--bl` | Corner control clusters |
| `.onrte-map` | MapLibre map container |
| `.onrte-panel` | Bootstrap offcanvas side panel |
| `.onrte-info-panel` | Info panel content (Map View + About + Privacy + Attribution) |
| `.onrte-attribution-chip` | Bottom-left attribution chip |
| `.onrte-map.panel-open` / `.onrte-controls.panel-open` | Shift right when the panel is open on desktop |
| `--onrte-panel-width` | CSS custom property: panel width (set in theme.scss) |
