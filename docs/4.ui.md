# UI — `useUI`

`useUI` manages all application UI state: responsive breakpoints, the side panel, and first-load detection. The map chrome is two components — the corner controls overlay (`src/components/ui/controls.vue`) and the side panel (`src/components/ui/panels.vue`). There is no top navigation bar.

---

## Usage

```js
import { useUI } from "@/composables/useUI.js";

const { isDesktop, isPanelVisible, setActivePanel, openPanel } = useUI();
```

State is cached per instance in a module-level `Map` keyed by `instanceId` (see [Instances](./2.instances.md)).

---

## Responsive breakpoints

`useUI` tracks `window.innerWidth` via a resize listener and exposes three computed flags.

| Computed    | Type      | Condition               |
| ----------- | --------- | ----------------------- |
| `isDesktop` | `boolean` | `width >= 992px`        |
| `isTablet`  | `boolean` | `768px ≤ width < 992px` |
| `isMobile`  | `boolean` | `width < 768px`         |

The corner chips render at every breakpoint; only the panel behaviour changes with width.

## Corner controls

[`src/components/ui/controls.vue`](../src/components/ui/controls.vue) renders a full-screen, click-through overlay (`.onrte-controls`) with four corner clusters (`.onrte-corner--tl` / `--tr` / `--br` / `--bl`):

| Corner       | Control                                                                                        | ID                    |
| ------------ | ---------------------------------------------------------------------------------------------- | --------------------- |
| Top-left     | Menu chip — toggles the side panel                                                             | `#menu-button`        |
| Top-right    | Locate chip (GPS cycle)                                                                        | `#locate-button`      |
| Bottom-right | Feature buttons registered with `position: 'bottom-right'` (e.g. Record, `#recordings-button`) | feature-defined       |
| Bottom-left  | Attribution chip — toggles the Info pane                                                       | `#attribution-button` |

- Every control is a **chip** — the `chip` variant of `IconButton` (`.icon-btn--chip`), a horizontal glass pill.
- Features register corner buttons with `addButton({ …, position: 'bottom-right' })`. Buttons without that position are not rendered ([`controls.vue:17`](../src/components/ui/controls.vue#L17)).
- On desktop the overlay mirrors the panel shift (`.onrte-controls.panel-open`), keeping controls over the visible map.
- The **attribution chip** shows the live style attribution, assembled by `buildAttribution` ([`src/utils/attribution.js`](../src/utils/attribution.js)) and exposed reactively by [`useAttribution`](../src/composables/useAttribution.js). It starts expanded, collapses to icon-only on the first map drag (MapLibre parity) and never expands again — the collapse state lives in [`useAttribution`](../src/composables/useAttribution.js) and is mirrored onto `.onrte-root` as `data-attrib-collapsed`. Clicking it toggles the Info pane. MapLibre's built-in attribution control is disabled (`attributionControl: false` in [`src/defaults/maplibre.js`](../src/defaults/maplibre.js)).

## Panel

The side column hosts one of two independent panes, tracked by `visiblePane` (`null | 'menu' | 'info'`):

- **Menu pane** (`'menu'`) — the tabbed menu. The menu is feature-only: tabs come from installed features. Features add tabs via `addButton({ panel: { ... } })` (e.g. Recordings) or register a panel-only tab (no corner button) via `addPanel({ id, icon, title, component })` — pushed into the `navigatorPanels` registry and rendered in `.panel-nav` via `panelTabs` ([`src/components/ui/panels.vue:40`](../src/components/ui/panels.vue#L40)). With the core features installed, the tab strip is Recordings, Offline Maps and Routes; the default active tab is the first feature tab (`record`).
- **Info pane** (`'info'`) — the Info panel ([`src/components/panels/info.vue`](../src/components/panels/info.vue)), rendered directly without the tab strip. It merges the former View, About and Privacy panels: an unheaded share block (share URL, copy, OpenStreetMap links) that leads the panel; an About branding row (`.onrte-about-section`) — the "Free, private & Open-Source" tagline (linking to the OpenGIS GitHub repo) beside the OGIS logo (`.onrte-about-logo`); a Privacy section with a heading and one-line summary plus a `<details>` disclosure whose summary label swaps between "Read more" and "Read less"; and a sticky, unheaded Attribution footer (`.onrte-attribution-section`) that content scrolls behind.

On desktop (`isDesktop`), the app opens the **Info pane** automatically on load. Mobile opens no pane on load; the menu pane is only opened by the user (menu chip or a feature button).

The two panes are separate: opening the Info pane never changes the menu's active tab, so switching between them preserves your position in the menu. `activePanel` only ever holds a menu tab id.

### `setActivePanel(id)` — switch the menu's active tab

```js
setActivePanel("record");
```

Emits a `panel:change` event. Only meaningful for the menu pane — never set to `'info'`. If the id is not among the available tabs (stale session, feature not installed), the pane falls back to the first available tab.

### `openPanel()` / `openInfo()` — open a pane

```js
setActivePanel("record");
openPanel(); // menu pane
openInfo(); // info pane
```

Both set `isPanelExpanded` to `true`.

### `togglePanel()` / `toggleInfo()` / `closePanel()`

- `togglePanel()` — toggles the menu pane (if the info pane is showing, switches to the menu)
- `toggleInfo()` — toggles the info pane (if the menu pane is showing, switches to info)
- `closePanel()` — closes whichever pane is visible, without changing the active tab

## Full API

### State (refs)

| Name              | Type                       | Description                                                 |
| ----------------- | -------------------------- | ----------------------------------------------------------- |
| `width`           | `number`                   | Current `window.innerWidth`                                 |
| `visiblePane`     | `null \| 'menu' \| 'info'` | Which pane the side column is showing                       |
| `isPanelExpanded` | `boolean`                  | Panel expanded (mobile)                                     |
| `activePanel`     | `string`                   | Active menu tab ID (default: first feature tab, `'record'`) |
| `isFirstLoad`     | `boolean`                  | True when no persisted view exists                          |
| `showAboutModal`  | `boolean`                  | Welcome modal visible                                       |

### Computed

| Name             | Type      | Description              |
| ---------------- | --------- | ------------------------ |
| `isDesktop`      | `boolean` | `width >= 992px`         |
| `isTablet`       | `boolean` | `768px ≤ width < 992px`  |
| `isMobile`       | `boolean` | `width < 768px`          |
| `isPanelVisible` | `boolean` | Any pane is visible      |
| `isMenuVisible`  | `boolean` | The menu pane is visible |
| `isInfoVisible`  | `boolean` | The info pane is visible |

### Actions

| Name                   | Signature | Description                          |
| ---------------------- | --------- | ------------------------------------ |
| `setActivePanel`       | `(id)`    | Switch menu tab, emit `panel:change` |
| `openPanel`            | `()`      | Open and expand the menu pane        |
| `openInfo`             | `()`      | Open and expand the info pane        |
| `togglePanel`          | `()`      | Toggle the menu pane                 |
| `toggleInfo`           | `()`      | Toggle the info pane                 |
| `closePanel`           | `()`      | Close whichever pane is visible      |
| `togglePanelExpanded`  | `()`      | Toggle expanded state                |
| `setPanelExpanded`     | `(value)` | Set expanded state                   |
| `setFirstLoadComplete` | `()`      | Mark first load complete             |
| `closeAboutModal`      | `()`      | Hide modal, mark first load complete |
| `openAboutModal`       | `()`      | Show modal                           |

## CSS classes

The main structural classes used by the app:

| Class                                                  | Element                                                          |
| ------------------------------------------------------ | ---------------------------------------------------------------- |
| `.onrte-root`                                          | Root div wrapping everything                                     |
| `.onrte-controls`                                      | Corner-controls overlay (click-through)                          |
| `.onrte-corner--tl` / `--tr` / `--br` / `--bl`         | Corner control clusters                                          |
| `.onrte-map`                                           | MapLibre map container                                           |
| `.onrte-panel`                                         | Bootstrap offcanvas side panel                                   |
| `.onrte-info-panel`                                    | Info panel content (share block + About + Privacy + Attribution) |
| `.onrte-attribution-section`                           | Sticky frosted-glass attribution footer in the Info panel        |
| `.onrte-attribution-chip`                              | Bottom-left attribution chip                                     |
| `.onrte-map.panel-open` / `.onrte-controls.panel-open` | Shift right when the panel is open on desktop                    |
| `--onrte-panel-width`                                  | CSS custom property: panel width (set in theme.scss)             |
