# GeoJSON — `useGeoJSON`

`useGeoJSON` provides a simple interface for rendering GeoJSON features on the map. It manages a single shared MapLibre source and data-driven style layers for points, lines, and polygons — you never call `addSource`, `addLayer`, or `setData` directly.

Features set before the map is ready are queued and applied automatically on `map:ready`. Sources and layers are cleaned up on `destroy`.

---

## Quick start

```js
import { useGeoJSON } from "@/composables/useGeoJSON.js";

const geoJSON = useGeoJSON();
geoJSON.setFeature({
  type: "Feature",
  id: "pin",
  geometry: { type: "Point", coordinates: [-128.0094, 50.6539] },
  properties: {},
});
```

From a feature `install()` function, pass `instanceId` explicitly:

```js
const geoJSON = useGeoJSON(instanceId);
```

---

## API

### `setFeature(feature)`

Add or update a GeoJSON feature. The feature must have a top-level `id`.

```js
geoJSON.setFeature({
  type: "Feature",
  id: "track",
  geometry: {
    type: "LineString",
    coordinates: [
      [-128.0094, 50.6539],
      [-128.05, 50.67],
    ],
  },
  properties: {
    "ogis.color": "#39d353",
    "ogis.width": 4,
    "ogis.opacity": 0.9,
  },
});
```

Calling `setFeature` with the same `id` replaces the existing feature.

Supported geometry types: `Point`, `MultiPoint`, `LineString`, `MultiLineString`, `Polygon`, `MultiPolygon`.

### `removeFeature(id)`

```js
geoJSON.removeFeature("track");
```

### `clearFeatures()`

```js
geoJSON.clearFeatures();
```

### `setDefaults(defaults)`

Set default style values. Affects all future `setFeature()` calls and immediately re-renders existing features that have no explicit style property.

```js
geoJSON.setDefaults({
  line: { color: "#39d353", width: 4, opacity: 0.9 },
  point: { radius: 8 },
  polygon: { fillOpacity: 0.3 },
});
```

---

## Style properties

Style is driven by `ogis.*` properties on the GeoJSON feature.

### All types

| Property       | Default                        | Description        |
| -------------- | ------------------------------ | ------------------ |
| `ogis.color`   | auto-assigned bright           | Fill/stroke colour |
| `ogis.opacity` | 0.85 (line/polygon), 1 (point) | Layer opacity      |

### Lines

| Property     | Default |
| ------------ | ------- |
| `ogis.width` | 3       |

Line layers always use `round` cap and join.

### Points

| Property      | Default |
| ------------- | ------- |
| `ogis.radius` | 6       |

Points are rendered as circles with a 1.5 px white stroke.

### Polygons

| Property           | Default |
| ------------------ | ------- |
| `ogis.fillOpacity` | 0.4     |

Polygons get a fill layer (`ogis.fillOpacity`) and an outline layer (`ogis.opacity`).

---

## Auto-assigned colours

When a feature has no `ogis.color`, `useGeoJSON` assigns a persistent random colour from a set of visually distinct bright primaries. The same colour is reused for all updates to that feature ID and released on remove/clear.

---

## How it works

A single MapLibre source (`ogis-geojson`) holds a `FeatureCollection`. Four style layers are created once on `map:ready`:

| Layer ID                       | Type     | Filters                     |
| ------------------------------ | -------- | --------------------------- |
| `ogis-geojson-polygon-fill`    | `fill`   | Polygon, MultiPolygon       |
| `ogis-geojson-polygon-outline` | `line`   | Polygon, MultiPolygon       |
| `ogis-geojson-line`            | `line`   | LineString, MultiLineString |
| `ogis-geojson-point`           | `circle` | Point, MultiPoint           |

All style properties are data-driven via MapLibre expressions on `ogis.*` feature properties. All layers and the source are removed when the app is destroyed.
