# Theme

On Route uses a custom Bootstrap 5.3 theme built in SCSS with a green palette. The UI is intentionally muted and translucent so it blends with the map.

---

## How it works

`src/assets/sass/theme.scss` is the single source of truth for the visual style. It:

1. Imports Bootstrap's Sass functions
2. Declares palette variables that override Bootstrap's defaults
3. Imports the full Bootstrap component set
4. Applies On Route-specific overrides for the navbar, panel, tabs, and form elements

---

## Palette

The four palette variables in `#2`:

```scss
$app-green: #39d353;  // primary accent (buttons, links, active states)
$app-black: #111111;  // always-dark navbar background
$app-white: #ffffff;  // light-mode panel background
$app-ink:   #1a1f1a;  // body text
```

These feed into Bootstrap's variable system — changing them automatically recolours buttons, links, badges, focus rings, and more.

---

## Bootstrap variable overrides

Any Bootstrap 5.3 variable can be overridden in `#3`, between the functions import and the infrastructure imports:

```scss
@import "bootstrap/scss/functions";        // #1 — must be first

// #2 palette + #3 Bootstrap overrides
$primary:       $app-green;
$body-bg:       $app-white;
$font-size-base: 0.9375rem;                // 15 px (compact)

@import "bootstrap/scss/variables";        // #4
@import "bootstrap/scss/variables-dark";
@import "bootstrap/scss/maps";
@import "bootstrap/scss/mixins";
@import "bootstrap/scss/root";

// #5 Bootstrap components
// #6 On Route component overrides
```

Full list of Bootstrap variables: [Bootstrap 5.3 Sass variables source](https://github.com/twbs/bootstrap/blob/v5.3.8/scss/_variables.scss).

## Component overrides (`#6`)

### Top navigation bar (`.onrte-top .navbar`)

Always rendered with `data-bs-theme="dark"` for a consistent dark anchor. Frosted-glass treatment lets the map palette bleed through:

```scss
.onrte-top .navbar {
  background: rgba($app-black, 0.88) !important;
  backdrop-filter: blur(12px) saturate(180%);
  border-bottom: 1px solid rgba(255, 255, 255, 0.06);
}
```

### Side panel (`.onrte-panel`)

Semi-transparent background so the map remains visible behind the panel:

```scss
.onrte-panel {
  --bs-offcanvas-bg: rgba(247, 245, 240, 0.94);
  backdrop-filter: blur(18px) saturate(160%);
}

[data-bs-theme="dark"] .onrte-panel {
  --bs-offcanvas-bg: rgba(17, 17, 17, 0.92);
}
```

Panel width is controlled via a CSS custom property:

```scss
:root {
  --onrte-panel-width: 340px;
}
```

### Icon buttons (`.icon-btn`)

Inactive icons use `--bs-secondary-color`. The active panel state and hover use `--bs-primary` with a 0.15 s ease transition. The `[aria-pressed="true"]` rule must live in section `#6e`:

```scss
.icon-btn {
  &[aria-pressed="true"] {
    color: var(--bs-primary);
  }
  &:hover {
    color: var(--bs-primary);
  }
}
```

### Dark mode

Bootstrap 5.3's `data-bs-theme` system is fully supported. The app has no in-app toggle and stores no theme preference — it always follows the operating system/browser `prefers-color-scheme` setting:

- [`useSettings`](../src/composables/useSettings.js) derives `resolvedTheme` (`'light'` or `'dark'`) and `isDark` from a `matchMedia('(prefers-color-scheme: dark)')` change listener, so runtime OS changes apply immediately.
- [`App.vue`](../src/App.vue) applies `:data-bs-theme="resolvedTheme"` on `.onrte-root` — the single DOM application point.
- `useSettings` also emits `theme:change` (`'dark'` / `'light'`) on the shared emitter when the system preference changes. It has no consumers yet — reserved for future map style integration.

On Route-specific overrides include dark variants for the panel.
