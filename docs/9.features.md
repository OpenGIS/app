# Features

A feature is a self-contained bundle of logic, a panel, and (optionally) a map-corner control chip. Features are installed from `src/main.js` before the app mounts.

---

## Feature structure

A feature is a plain object with an `install(ctx)` method:

```
src/features/{name}/
  index.js            ← feature object + business logic
  {Name}Button.vue    ← corner control chip (optional)
  {Name}Panel.vue     ← side panel tab (optional)
```

---

## Feature context

`install(ctx)` receives a context object built in `src/main.js`:

```js
{
  app,           // Vue app instance
  instanceId,    // string — for storage scoping
  emitter,       // EventEmitter singleton
  useStorage,    // (namespace, defaults) → pre-scoped reactive storage
  useSettings,   // () → OS-derived settings (theme, units); no instanceId, nothing stored
  useLocale,     // () → locale resolved per instance; in-memory cache, nothing stored
  getMap,        // () → MapLibre map instance or null
  onMapReady,    // (cb) → cb({ map, addSource, addLayer }) with auto-cleanup
  provide,       // (key, value) → app.provide
  addButton,     // (config) → adds a corner control chip (+ panel tab)
  addPanel,      // (config) → adds a panel tab
}
```

### `addButton(config)`

Registers a control chip in the map's bottom-right corner (and, when a `panel` is supplied, a side-panel tab):

```js
addButton({
  id: "my-feature", // panel tab id — match it in setActivePanel()
  icon: "route", // used when no component is supplied
  position: "bottom-right", // the only rendered position
  component: MyButton, // Vue component rendering an IconButton chip
  panel: {
    title: "My Feature",
    component: MyPanel,
  },
});
```

- Buttons are rendered by the corner-controls overlay ([`src/components/ui/controls.vue:24`](../src/components/ui/controls.vue#L24)); a button without `position: 'bottom-right'` is not rendered.
- With a `panel`, the button also becomes a panel tab. A plain (icon/label) button opens that panel on click; a `component` button handles its own click and can call `setActivePanel()` / `openPanel()` itself.
- `id` should match the panel tab id used with `setActivePanel()` — Recordings, for example, uses `'record'`.

### `addPanel(config)`

Registers a panel-only tab in the side panel navigation (`.panel-nav`) — no corner button. The config is pushed into the `navigatorPanels` registry ([`src/main.js:105`](../src/main.js#L105)) and rendered as a tab via `panelTabs` ([`src/components/ui/panels.vue:39`](../src/components/ui/panels.vue#L39)):

```js
addPanel({
  id: "my-feature",
  icon: "cloud-arrow-up",
  title: "My Feature",
  component: MyPanel,
});
```

### `onMapReady(callback)`

Registers a callback that fires once the MapLibre map is ready. The callback receives `{ map, addSource, addLayer }`. Sources and layers added via these helpers are automatically removed on app destroy:

```js
onMapReady(({ map, addSource, addLayer }) => {
  addSource('my-source', { type: 'geojson', data: featureCollection });
  addLayer({ id: 'my-layer', type: 'circle', source: 'my-source', paint: { ... } });
});
```

## Registering a feature

In `src/main.js`, import and install the feature before `app.mount()`:

```js
import { RecordingsFeature } from "./features/recordings/index.js";

RecordingsFeature.install(featureCtx);
```

## Recordings — worked example

The Recordings feature (`src/features/recordings/`) records GPS tracks using the Geolocation API, renders them live on the map via `useGeoJSON`, saves them to `localStorage`, and exports them as GPX files.

### Feature object (`index.js`)

```js
export const RecordingsFeature = {
  install({ useStorage, useSettings, getMap, instanceId, provide, addButton }) {
    const stored = useStorage("recordings", { saved: [], active: null });
    const { isMetric } = useSettings();
    const geoJSON = useGeoJSON(instanceId);

    // ... state, GPS watch, GeoJSON rendering ...

    addButton({
      id: "record",
      icon: "route",
      position: "bottom-right",
      component: RecordButton,
      panel: {
        title: "Recordings",
        component: RecordingsPanel,
      },
    });

    provide("recordings", {
      state,
      elapsed,
      distance,
      isMetric,
      start,
      pause,
      resume,
      discard,
      save,
      deleteRecording,
      downloadGPX,
      showOnMap,
    });
  },
};
```

### GeoJSON integration

The active recording is rendered as a live `LineString` using green (`#39d353`) via `useGeoJSON`:

```js
geoJSON.setFeature({
  type: "Feature",
  id: "recordings-active-track",
  geometry: { type: "LineString", coordinates: coords },
  properties: {
    "ogis.color": "#39d353",
    "ogis.width": 3,
    "ogis.opacity": 0.85,
  },
});
```

### Storage

Active recording and saved list are persisted under `ogis_recordings_{instanceId}`:

```js
useStorage("recordings", { saved: [], active: null });
```

### GPX export

`toGPX(recording)` generates a standard GPX 1.1 string with `<trkpt>` elements and creator tag `creator="ogis.app"`.

### Components

- **`RecordButton.vue`** — corner chip showing Record / Recording / Paused; injects `recordings` from `provide` and opens the Recordings panel
- **`RecordingsPanel.vue`** — lists saved recordings with duration/distance; exports GPX; injects `recordings`

### State shape

```js
{
  isRecording: false,
  isPaused: false,
  points: [],          // [{ lat, lng, t }]
  startTime: null,     // ms timestamp
  saved: [],           // [{ id, timestamp, points, distance, duration }]
}
```

## Adding a new feature

1. Create `src/features/{name}/index.js` with an `install(ctx)` method
2. Create `src/features/{name}/{Name}Button.vue` and `{Name}Panel.vue` as needed
3. Register in `src/main.js`: `MyFeature.install(featureCtx)`
4. Add unit tests in `tests/unit/` for pure logic
5. Add an E2E spec in `tests/e2e/features/{name}.spec.js` for integration
